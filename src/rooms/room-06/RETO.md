# VI · Intercepta a Eric

El reto vigente usa un radar horizontal de intercepción: cuatro controles deslizantes, una trayectoria que se puede arrastrar y ensayos con reloj compartido. Consulta [README.md](README.md) para las condiciones, ecuaciones, solución de referencia y restricciones del modelo.

El antiguo ejercicio de MRUA vertical (1800 m, 120 m/s, empuje de 13810 N) queda reemplazado. Se conserva en el historial de Git anterior a este cambio. La cinemática posterior de Iván y José Luis se mantiene. Tests: `tests/interception.cjs`, `tests/rocket.cjs` y `tests/finale.cjs`.
