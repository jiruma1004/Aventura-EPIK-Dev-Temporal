# Recursos de las cinemáticas

Esta carpeta contiene fondos, atlas WebP y previsualizaciones GIF usados por las escenas del juego.

- Los atlas de fondos se dividen en paneles mediante el código de cada escena.
- Los sprites transparentes se anclan a los pies para conservar su posición al cambiar de pose.
- Diálogos, partículas, confeti y efectos se dibujan con Canvas y HTML.
- Los recursos se cargan progresivamente según la ruta seleccionada.

La implementación está en `src/cinematics/`. Las notas privadas de producción y los materiales de referencia se conservan fuera de esta publicación. El juego no necesita esas notas para funcionar.
